# Britta Rethfeldt – Premium Relaunch Demo

Statische, responsive Demo-Website ohne Build-Schritt.

## Start
`index.html` direkt im Browser öffnen oder den Ordner auf GitHub Pages / Netlify / Vercel hochladen.

## Bilder
Die eingebundenen Fotos stammen aus dem bereitgestellten Bildmaterial und liegen für das Web optimiert unter `assets/images/`. Brittas Auftraggeber bestätigt, dass die erforderlichen Rechte an den zur Verfügung gestellten Fotos vorliegen.

## Kontaktformular
Die Demo öffnet beim Absenden die lokale E-Mail-App (`mailto:`). Für Produktion sollte ein echter Formular-Endpunkt ergänzt werden.

## Technisch
- Responsive Desktop / Tablet / Mobile
- Eigene Über-mich-Seite mit Brittas Haltung und ihren beruflichen Facetten
- Portfolio mit ausgewählten Bildern von Trauungen, Orten und Details
- Sticky Header + Mobile Navigation
- Scroll-Reveal mit `prefers-reduced-motion`
- FAQ Accordion
- Mailto-Kontaktflow
- Keine Frameworks, keine Build-Tools

## Rechtliche Seiten – vor Veröffentlichung prüfen
Impressum und Datenschutz sind Entwürfe auf Basis der bisherigen Website und der aktuellen technischen Vorschau. Betreiberangaben, Wirtschafts-ID, Verbraucherstreitbeilegung sowie Bildnachweise mit Britta abgleichen. Die Datenschutzseite benötigt insbesondere den tatsächlichen Hosting-Anbieter, dessen Speicherfristen, etwaige Datenempfänger und Drittlandübermittlungen. Die Schriften DM Sans und DM Serif Display werden lokal eingebunden; die OFL-Lizenztexte liegen im Schriftordner. Nach Änderung der Technik Datenschutzerklärung erneut abgleichen. Die Texte fachlich prüfen lassen und bei Änderungen der Technik aktualisieren. Bei vereinbarter Urhebernennung die zugehörigen Bildnachweise ergänzen.

## Stimmprobe
Die von Britta bereitgestellte Stimmprobe ist als lokale MP3 unter `assets/audio/britta-stimmprobe.mp3` eingebunden und wird über den Player auf der Startseite abgespielt.
