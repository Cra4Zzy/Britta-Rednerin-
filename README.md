# Britta Rethfeldt – Premium Relaunch Demo

Statische, responsive Demo-Website ohne Build-Schritt.

## Start
`index.html` direkt im Browser öffnen oder den Ordner auf GitHub Pages / Netlify / Vercel hochladen.

## Bilder
Die Demo verwendet öffentlich erreichbare Bilddateien aus Britta Rethfeldts bestehender Website (Wix CDN), damit im Konzept ihre echte Bildwelt sichtbar ist. Für eine finale Kundenwebsite sollten die Originaldateien mit ausdrücklicher Freigabe lokal ins Projekt übernommen und optimiert werden.

## Kontaktformular
Die Demo öffnet beim Absenden die lokale E-Mail-App (`mailto:`). Für Produktion sollte ein echter Formular-Endpunkt ergänzt werden.

## Technisch
- Responsive Desktop / Tablet / Mobile
- Sticky Header + Mobile Navigation
- Scroll-Reveal mit `prefers-reduced-motion`
- FAQ Accordion
- Mailto-Kontaktflow
- Keine Frameworks, keine Build-Tools
